# Sniper 狩獵

狙擊視角的休閒狩獵遊戲原型（網頁版，Three.js + TypeScript）。設計見 [docs/DESIGN.md](docs/DESIGN.md)。

```bash
npm install
npm run dev     # 開發伺服器
npm test        # 單元測試（彈道等）
npm run build   # 型別檢查 + 打包
```

## 操作
| | 手機（直向） | 桌機 |
|---|---|---|
| 移動 | 左半邊拖曳（推到底奔跑） | WASD、Shift 奔跑 |
| 看／瞄準 | 右半邊拖曳 | 滑鼠（點畫面鎖定游標） |
| 開鏡 | 右側準星圖示 | 右鍵 |
| 開火 | 按住閉氣、放開開火、滑出取消 | 左鍵按住／放開 |
| 歸零 | 開火鍵上方滑桿 | 滾輪 |
| 倍率 | 鏡下方 4x/8x/16x | Z |
| 站／趴 | 右側人形圖示 | C |
| 追蹤 | 右側蹄印圖示 | T（E 讀取準星下的線索） |
| 暫停 | 左上選單 | Esc／P |
